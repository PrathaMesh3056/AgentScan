Rule 1

Typography & Sizing

  • Fluid Scaling: clamp(24px, 4vw, 40px) for H1.
  • Minimum 16px: Body copy never drops below 16px to prevent iOS auto-zoom bug.
  • Two-Weight Rule: Title (700) + Subtitle/Body (400).
  • Line Leading: 1.5–1.6 line-height on textures.
  • Line-Length: Constrained strictly to 45–75 characters.
Rule 2

Placement & Positioning

  • Safe Zone Rule: Text strictly placed in low-detail quiet zones.
  • Focal Avoidance: Never over primary product or human subject.
  • Left-Aligned: Uniform left alignment for body copy; center only for ≤ 3 line headers.
  • Aspect Ratio: Enforced with aspect-ratio: 16/9.
  • Anchoring: object-position: right center; for crop defense.
Rule 3

Contrast & Accessibility

  • WCAG Standard: ≥ 4.5:1 for body; ≥ 3:1 for bold headers.
  • Squint Test: Live test button blurs canvas to confirm shape survival.
  • Gradient Scrim: rgba(0,0,0,0.4–0.88) dark scrim layer.
  • Backdrop Blur: backdrop-filter: blur(8px) for glass isolation.
  • Discreet Shadow: 0 2px 4px rgba(0,0,0,0.35).
Rule 4

Frontend Performance

  • No Baked Text: Live DOM HTML/CSS for SEO, accessibility & sharp DPI.
  • Cover Fit: object-fit: cover on all media.
  • Clamp Typography: Fluid CSS clamp() functions throughout.
  • Stacking Isolation: isolation: isolate prevents blending filter bleed.
